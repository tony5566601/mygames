# 三國・無雙生存

瀏覽器單機生存遊戲：選擇關羽、趙雲或諸葛亮，在黃巾軍的圍攻下存活三分鐘。武將自動攻擊；擊敗敵人後收集軍功，升級時選擇強化能力。兩分鐘時黃巾首領會加入戰場。

## 開始遊戲

直接雙擊 `index.html`，即可在瀏覽器遊玩，不需要 Python、本機伺服器或網路連線。請將 `index.html`、`style.css`、`simulation.js` 與 `game.js` 保留在同一個資料夾。

- 移動：WASD、方向鍵，或觸控畫面上的方向按鈕。
- 攻擊：自動攻擊範圍內最近的敵人。
- 暫停：右上角按鈕或 Esc。
- 升級：拾取敵人掉落的金色軍功，從三項能力中選擇一項。

## 測試

需要 Node.js，在此資料夾執行 `npm test`。

## 未來多人擴充

`simulation.js` 將固定時間步長的遊戲狀態更新與畫面、輸入分開；狀態是可序列化的純資料，亂數種子也保存在狀態中。未來可由伺服器持有權威狀態，接收玩家輸入並定期廣播快照。現階段只有單人模型，尚未實作多人玩家、伺服器、房間、網路同步或斷線處理。
